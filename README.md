# GameForge MCP Server 🎮⚡🕹️

Universal Autonomous Game Development, Unity/Godot/Three.js, Gameplay Mechanics, Procedural Generation, Performance & Store Release Engine MCP Server for **Cursor, Claude Code, Windsurf, and Autonomous AI Agents**.

## 🌟 Core Capabilities:
- 👑 **Master 1-Shot Outcome Engine (`autonomous_game_architect`):** Ingests the game concept to synthesize a complete blueprint in one call: engine decision matrix (Godot vs Unity vs Three.js vs Unreal vs GameMaker), core loop design, architecture plan (state machines, signals, data-driven design), art direction guidance, monetization, and a Steam/itch.io/mobile launch roadmap.
- 🎮 **Gameplay Mechanics Generator (`generate_gameplay_mechanics`):** Production player controllers with input buffering, coyote time and variable jump height; enemy AI finite state machines; combat, inventory, dialogue and save systems — in Unity C#, Godot GDScript, or Three.js TypeScript.
- 🗺️ **Procedural Generation Engine (`implement_procedural_generation`):** Cellular automata caves with connectivity guarantees, wave function collapse dungeons, noise terrain, weighted loot tables with pity timers, and dynamic difficulty adjustment — all seed-reproducible for debugging.
- ⚡ **Performance Optimizer (`optimize_game_performance`):** Profile-first diagnosis plans, object pooling (bullets/particles/enemies), draw call batching, the 16.6ms frame budget table, and before/after verification steps for a locked 60 FPS.
- 🚀 **Game Release Kit (`prepare_game_release`):** Steam page copy (hook-first short description, tags strategy), capsule/screenshot/trailer asset checklists, Steamworks build submission, wishlist marketing plans, and a launch-day checklist with press pitch templates.
